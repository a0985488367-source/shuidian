# 水電工地帳

給水電行用的手機網頁，兩頁：

- **工單**：地址、更換了什麼、實收、成本（材料／工錢／其他），算出公司淨收；可一鍵複製成 LINE 格式，看每月合計。
- **庫存**：每樣材料進了多少、1 單位多少錢、剩餘多少；工單裡用到庫存的材料會自動扣。

- 網址：https://a0985488367-source.github.io/shuidian/
- 整個工具只有 `index.html` 一個檔案，推到 `main` 會自動部署到 GitHub Pages。
- 資料存在每個使用者自己手機的瀏覽器裡（localStorage），不在這個程式庫。
  刪掉或改這個程式庫不會刪到任何人的資料；但程式庫要保持公開，網頁才打得開。
